# AdventureWorks_Dashboard

📊 Overview

This project is an interactive Power BI Sales Analytics Dashboard built using the AdventureWorks dataset.

The dashboard is designed to provide a clear view of sales performance through key performance indicators, geographic analysis, sales trends, order status analysis, and product-level insights.

The report combines multiple Power BI visualizations to help users explore sales performance from different perspectives and identify the factors contributing to overall revenue.

🎯 Objectives

The main objectives of this project were to:

Monitor important sales KPIs.
Analyze total sales and revenue performance.
Examine sales performance across different territories.
Track sales trends over time.
Analyze order status distribution.
Compare actual sales against a predefined target.
Identify the contribution of different product categories.
Drill down into sales performance by territory and product subcategory.
Present business insights through an interactive Power BI dashboard.
📑 Dashboard Pages
1. Home Page

The Home Page acts as the landing page for the report and provides navigation to the different sections of the dashboard.

2. Overview

The Overview page provides a high-level view of the company's sales performance.

It includes several KPI cards covering:

Number of Orders
Subtotal
Total Tax
Total Freight
Total Due

The page also contains visualizations for:

Sales by Territory using a geographic map.
Order Status Distribution using a pie chart.
Sales Trends Over Time using a line chart.

This page provides a quick overview of the company's overall sales performance and how it changes across territories and time periods.

3. Analysis

The Analysis page focuses on deeper sales analysis and performance evaluation.

It includes:

Target vs. Actual Sales using a KPI visualization.
Sales by Product Category using a waterfall chart.
Sales Decomposition using a decomposition tree.
Detailed sales analysis across territories and product subcategories.
Additional contextual information about selected sales records.

The decomposition tree allows users to break down total sales into different dimensions and investigate which territories and product subcategories contribute to overall performance.

4. Tooltip

The report also includes a custom tooltip page that provides additional contextual information when interacting with certain dashboard visuals.

📈 Key KPIs

The dashboard tracks several important sales metrics, including:

These measures provide insight into both overall sales volume and financial performance.
